# Wave 3 (LAST, only if time after 3:30 PM): the room test

Branch `lane/g-room-test`. Owns `server/src/roomtest/**`, `web/src/roomtest/**`.

## Idea
Prove the simulator on real people in the building. Predict which of 3 generated restaurant concepts
NOVA hackers would pre-order, then ask them, and show prediction vs reality on stage.

## Build
- Build a "NOVA hackers" population for the room: ~200 residents, segment mostly undergrad and grad,
  location = Tepper (Swartz Center), Saturday dinner, using Lane C's generator with an override.
- A public pre-order page (`/r`): three concept cards (generated by Lane B), "Which would you order
  for dinner tonight?" plus optional "how much would you pay?". No payment, no food, no login.
  One vote per browser (localStorage) is enough.
- Before opening the poll, freeze the simulator's prediction (vote shares with bands) and save it with a timestamp.
- Results view: predicted vs actual shares side by side, n, and the time window. Honest even if it misses.
