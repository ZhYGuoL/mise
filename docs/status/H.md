# Lane H: start from an existing restaurant

- Works: `/import <name or Maps link>`, the "Existing restaurant" row on the empty state, and plain chat ("I run Noodlehead"). The chat agent's `import_restaurant` tool runs the same import. If a concept exists, the owner says yes on an approval card first. A question in the same message ("what if we stayed open till 2?") runs on the imported restaurant right after. New ideas still use `create_concept`, and a name that is not in the city gets a plain "not in the city". All of this was checked in the browser.
- Real data: name, address, neighborhood, cuisine, tier, rating, and hours from Google popular times, then the OSM tag, then cuisine defaults. The menu is "website" only when code finds each name and price on the page (Noodlehead, Everyday Noodles, The Porch). Else MODEL_FAST estimates it. An import costs about $0.001, and 12 places are cached in `data/import/`.
- With lane D merged, the hour chart shows Google's busy line for places with popular times (Noodlehead Friday: r 0.82, 35 to 46 orders). Brand colors, voice and logo are drafted, and fees are the city's typical $2.99 and 14%.
- Contracts: new `ImportRequest`, `ImportResponse`, `ImportPlace`, `ImportError`, and the `import` AgentEvent. Hooks outside my folders: the agent (`tools.ts`, `run.ts`, `prompt.ts`), `client.ts`, `session.ts`, `Thread.tsx`, `format.ts` (whole-week hours read as "Daily 12 PM to 10 PM"), `commands.ts`, `Composer.tsx`, `LeftPane.tsx`, `Canvas.tsx`, `HourChart.tsx`.
- Known issue (lane A): the user bubble in `Thread.tsx` does not wrap long words. An import clears the thread and versions, because it starts a new restaurant.
